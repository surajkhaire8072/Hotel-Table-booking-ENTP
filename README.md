# Aapla Nashta — Maharashtrian Breakfast Website

A responsive sample website for a Maharashtrian breakfast restaurant, with menu cards and a table booking demo form.

## Files
- `index.html` — website structure and menu
- `style.css` — responsive styling
- `script.js` — mobile navigation and demo booking interaction

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `aapla-nashta`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait a minute or two and open the Pages link shown on the Settings page. It will usually look like `https://YOUR-USERNAME.github.io/aapla-nashta/`.

## Customize before publishing
- Replace “Aapla Nashta” with your restaurant name if needed.
- Add your actual address and phone/contact details in `index.html`.
- Menu items and prices are sample/demo content; update them to match your restaurant.
- Food images use remote Unsplash image URLs and require an internet connection.

## Important booking note
This is a **front-end demonstration only**. The booking form creates a local confirmation message in the visitor's browser. It does not send reservations to restaurant staff or save them in a database. For real bookings, connect a secure backend or booking service.
